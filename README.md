# PROA + Serasa

Este repositório foi criado para registrar nossos estudos e atividades realizadas durante o curso do **Instituto PROA + Serasa**.

Durante as aulas, desenvolvemos **sites simples, exercícios e projetos**, colocando em prática os conteúdos aprendidos em cada aula.

##  O que estudamos

Ao longo do curso, trabalhamos com:

* HTML
* CSS
* JavaScript
* Git
* GitHub
* Figma

Cada dia de aula possui seu próprio conteúdo e, em muitos casos, desenvolvemos um **site ou atividade durante a própria aula**. Assim, este repositório serve para acompanhar nossa evolução e guardar tudo o que foi desenvolvido durante o curso.

Além das atividades diárias, também desenvolvemos **projetos maiores**, utilizando os conhecimentos aprendidos ao longo da formação.
